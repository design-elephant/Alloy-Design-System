--alloy-sys-*

Color roles

Every component reads a semantic role, never a raw value. Roles re-map per theme — toggle the theme in the header and every swatch below follows. Pink and orange are peer accents; pure red is kept for errors only.

--alloy-gradient-*

Gradients for depth

Pink ↔ orange. The gradient button variant, brand marks, hero moments. --alloy-gradient-depth is an ambient two-corner wash for large backgrounds — depth without a hard edge.

--alloy-gradient-depth

--alloy-type-*

Type scale

One family — Inter, via --alloy-font-sans — across fifteen roles. Tight tracking on display, comfortable leading on body for fast scanning. Sizes in px.

--alloy-elevation-*

Elevation

Five levels of clean neutral-grey shadow. Brand depth is a separate job — the pink↔orange gradient tokens (--alloy-gradient-depth for large surfaces), not tinted shadows.

Components

the rules that keep it scannable

Three colors, three jobs

The palette stays legible because each hue has exactly one role and doesn't drift into the others'.

Pink leads

Primary actions, links, active states, focus rings — and the first stop of every gradient. AA-safe primary/40 for text; the brand #E80C7A for large / chrome.

Orange is a peer

A full second accent — alternate CTAs, highlights, and the orange end of the gradient. Text-safe secondary/40, brand #FF540D.

Pure red is off-limits

The one hot hue never used decoratively — reserved for error alone, so destructive and invalid states read as outside the palette.
